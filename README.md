# Asservissement Numérique - LQR avec Observateur

## 📌 Description
Ce projet présente la commande optimale LQR associée à un observateur d’état pour l’asservissement d’un système dynamique.

---

## 🧠 Modèle
Le système est représenté en espace d’état sous la forme :

- Matrices : A, B, C  
- Représentation : modèle dynamique linéaire

---

## ⚙️ Méthode utilisée
- Commande optimale **LQR (Linear Quadratic Regulator)**
- Observateur d’état de **Luenberger**
- Simulation numérique avec Python

---

```bash
python -m venv env
./env/Script/activate
pip install -r requirements.txt
